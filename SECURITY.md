# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/xiangzhang-coding/cuda-learning-site/security/advisories/new). Do not include exploit details, credentials, tokens, private paths, or sensitive logs in a public Issue or Pull Request.

Use [GitHub Issues](https://github.com/xiangzhang-coding/cuda-learning-site/issues) for non-sensitive correctness, accessibility, content, source, and dependency reports.

## Supported surface

Security fixes target the current `main` branch. The public Learning Site is static and has no application API, database, account system, server rendering, hosted GPU backend, or browser CUDA execution. Deployment configuration is reviewed separately before production release.
