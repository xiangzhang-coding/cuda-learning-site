EX15 是独立、原创的 C++17 CUDA 可运行示例。它实现 row-major FP32 `C = alpha*A*B + beta*C`，并用 independent double CPU reference 与 finite abs-plus-rel tolerance 检查结果。网站不执行 CUDA，本页没有 timing、throughput、utilization、speedup 或 production-library comparison。

## 用途

先完成 A08。EX15 把 naive-to-tiled mental model 落实为一个 partial-safe project：三组 fixtures、one-block/one-output-tile ownership、zero-filled K tails、两个统一 barriers、guarded store 和 mismatch report。

## 获取 canonical project

[查看固定 EX15 project](https://github.com/xiangzhang-coding/cuda-learning-site/tree/4e68ba05ff2914a509cd0cb7f6bfc7c7dfd0f6d0/examples/ex15-tiled-gemm)，或[下载同一 revision](https://github.com/xiangzhang-coding/cuda-learning-site/archive/4e68ba05ff2914a509cd0cb7f6bfc7c7dfd0f6d0.zip)。项目目录是 `examples/ex15-tiled-gemm/`，页面与 canonical imports 使用同一 immutable pin。

## Matrix 合同

`A[M,K]`、`B[K,N]` 与 `C[M,N]` 都是 row-major。每个 output owner 计算 `C[row * N + col] = alpha * sum(A[row * K + p] * B[p * N + col]) + beta * C[row * N + col]`。Fixtures 是 hand-checkable `2x3x2`、all-partial/nonzero-beta `33x31x35` 与 aligned `32x32x32`。

## CPU reference

<CanonicalCode exampleId="EX15" range="cpu-reference" />

Reference 使用 double accumulation，先验证 dimensions/counts、pointers、finite inputs 与 finite scalars。Verifier 使用 `atol=1e-4`、`rtol=2e-5`，拒绝 non-finite candidate/reference 与负 tolerance，并报告 first mismatch。

## Tiled GEMM

<CanonicalCode exampleId="EX15" range="tiled-gemm" />

一个 `16x16` thread block 拥有一个 `16x16` output tile。每个 K slice 把 A/B partial loads guard 后 zero-fill 到两个 `float[16][16]` arrays，执行 barrier、16 products、第二个 barrier。Kernel 在 barrier 前没有 return，final C store 独立 guarded。

没有 architecture-specific variant：普通 FP32、shared memory 与 block barrier 已满足 CC 7.5 baseline。单一路径是所有 lanes 的 portable fallback；未引入 WMMA、Tensor Core、TF32、`cp.async` 或 toolkit-specific fork。

## Host model 边界

`make host-test` 只编译 pure C++17 header/test。它检查 hand oracle、三个 fixtures、near-zero absolute term、magnitude-scaled relative term、out-of-tolerance mismatch、NaN/infinity、negative tolerances 与 mismatch coordinates。成功打印 `host-reference: pass`，但不建立 CUDA compilation 或 execution。

## 构建合同

```sh
make preprocess DIALECT=c++17
make compile DIALECT=c++17
make link DIALECT=c++17
make inspect DIALECT=c++17
make host-test DIALECT=c++17
```

`scripts/compile-check.sh c++17 ex15 <result-dir>`执行 clean 及上述阶段，保留 logs、cubin list 与 PTX dump，绝不执行 CUDA binary。Artifact plan 是 native `sm_75` 加 `compute_75` PTX。

## 预期观察，不是运行记录

1. Each declared fixture should satisfy the finite atol + rtol * abs(reference) comparison against the independent double CPU reference.
2. The 33x31x35 fixture should exercise partial M, N, and K tiles while every thread reaches both block barriers in every K-tile iteration.
3. The portable FP32 baseline should preserve the declared alpha and beta contract without implying an architecture-specific instruction or performance result.
