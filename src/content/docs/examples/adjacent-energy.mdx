## 合同

前置：[P08](/frameworks/first-custom-operator/)与 [P09](/frameworks/operator-registration/)。对含 1 到 1,000,000 元素的一维连续 strided CPU/CUDA float32 或 float64 张量计算 `y[i]=(x[i+1]-x[i])^2`。返回同设备、同 dtype、新分配连续 n-1 输出，不修改输入、不产生别名。偏移连续视图可用，步长二、空输入、half/整数 dtype 或批量形状被拒绝。单元素返回空输出。不掩盖普通非有限算术。这是原创教学代码，不是改编的教程算子或性能基准。

## 自动求导

<CanonicalCode exampleId="EX22" range="autograd" />

q=2*diff(x)*g 时，左补零放置每条边对右端的正贡献，右补零放置对左端的负贡献。这样通过普通张量操作处理单元素并支持高阶导数。

## 构建、安装与执行

在新 CPython 3.12.14 虚拟环境中，从仓库根运行 `python -I scripts/pytorch-environment/check.py --install`，准备选定应用环境。GCC、Toolkit 另行准备。在 EX22 根目录执行：

```sh
bash scripts/check-wheel.sh
python -I verify.py --device cuda
```

第一条命令构建两条路径、安装 wheel、检查依赖、验证隔离已安装导入，并在无 GPU 条件执行 CPU 集成检查。第二条要求一个合适 CUDA 设备和兼容驱动，保守基线 570.124.06。CUDA 缺失不能称为通过的跳过。保留全部阶段退出码和诊断；即使源码运行正常，构建或导入失败也仍是失败。[实验（Lab）LAB13](/labs/build-custom-operator/)给出完整打包和环境清单（Environment Manifest）验收流程。
