## 学习目的

完成 Q10 后，用 VIS13 建立一个受限的单层 Roofline 心智模型：声明计算上限 `Pcompute`、声明路径带宽上限 `Bpath`、算术强度 `I` 和 workload rate，然后区分输入点位于带宽侧模型区域、屋脊点（ridge point）还是计算侧模型区域。Q09、A14 与 LAB09 是相关后续资源；它们不是本页的额外 prerequisite。

## 声明输入

四个控件保留原始字符串，只有按下“应用”才进入推导：

- **声明计算上限：** `100` 到 `100000 Gop/s`。
- **声明带宽上限：** `10` 到 `10000 decimal GB/s`，其中 `1 GB = 10^9 bytes`。
- **算术强度：** `0.01` 到 `10000 operations/byte`。
- **达到的 workload rate：** `0.01` 到 `100000 Gop/s`。

默认 `12000 Gop/s`、`800 decimal GB/s`、`8 operations/byte` 与 `5600 Gop/s` 是合成教学输入，不来自 GPU specification、profiler report、benchmark 或运行观察。页面严格拒绝空字符串、带空白的值、指数记法、`NaN`、`Infinity`、非正数与范围外数值。无效输入不会沿用上一张动态图的 geometry。

## 确定性模型规则

由于 `operations/byte × 10^9 bytes/second = 10^9 operations/second`，本页的 `I × Bpath` 可以直接得到 `Gop/s`。模型只执行以下推导：

- `ridge intensity = Pcompute / Bpath`
- `workload roof = min(Pcompute, I × Bpath)`
- `I < ridge` 为带宽侧模型区域，`I = ridge` 为屋脊点，`I > ridge` 为计算侧模型区域。
- workload rate 与 workload roof 比较后得到低于、位于或高于声明 roof。

SVG 使用固定 `0 0 720 420` viewBox 和固定对数式坐标域。斜实线、水平虚线、屋脊点菱形、workload 圆加十字、直接可见文字和语义表共同表达结构，因此颜色不是唯一线索。这个模型只有一组声明的 compute/bandwidth ceilings；它不冒充 Nsight Compute 的 current metric definitions 或 hierarchical rooflines。

## Mismatch audit

高于声明 roof 的点保持为有效、可重复的 `above-declared-roof` 状态。它表示四个输入彼此不一致，需要审计单位、operation counting rule、memory path、ceiling scope 与 provenance；浏览器不会静默截断点、改变输入或把它拒绝成“GPU 不可能”。模型区域也不会识别实际 workload 的限制原因。

## 证据边界

VIS13 不执行 CUDA、不读取 GPU、不调用 profiler，也不观察 workload。即使用户把测量值键入四个控件，这个动作也不会授予 Evidence Status。测量点必须由符合要求的 LAB09 Environment Manifest、口径、日志和来源承载。Compilation、runtime、expected-observation 与 recorded-observation arrays 全为空。

## 来源

[CUDA C++ Best Practices Guide 13.3 bandwidth chapter](https://docs.nvidia.com/cuda/cuda-c-best-practices-guide/index.html#bandwidth) 区分 theoretical 与 effective bandwidth，给出 `((Br + Bw) / 10^9) / time` 的 decimal GB/s 公式，并要求理论值与有效值使用相同 divisor。[Nsight Compute UI Rooflines page](https://docs.nvidia.com/nsight-compute/NsightCompute/index.html#rooflines) 记录 current 2026.2.1 GUI report 的 Rooflines section、hierarchical ceilings 与 chart controls。[Profiling Guide 2026.2.1 Roofline Charts](https://docs.nvidia.com/nsight-compute/ProfilingGuide/index.html#roofline-charts) 定义 arithmetic intensity、对数坐标、斜向 memory-bandwidth boundary、水平 peak-performance boundary 与 ridge point。
