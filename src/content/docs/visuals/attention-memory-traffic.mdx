## 学习目的

完成 [A11](/algorithms/attention-as-an-io-problem/) 后，用 VIS18 同时看见 score、normalization 与 value aggregation 的 logical IO。上轨物化完整 `S` 和 `P`，下轨让一个 query tile 扫过 key/value tiles，并把 temporary score tile、online row statistics 与 weighted accumulator 保留在 fast store。

## 固定 fixture 与边界

两组 self-attention shape 是 `N=8,d=4` 与 `N=16,d=8`，两组 score tile 是 `Br×Bc=4×4` 与 `8×8`。Storage 固定为 FP32，每个 counted element 为 4 byte；Q、K、V 已预先得到。模型排除 projection、mask、bias、dropout、backward、allocation、host-device transfer、cache line、transaction overfetch 与 spill。

这里的 boundary 是 stipulated slow store 和 fast store 之间的 logical element transfer。它不是 GPU DRAM counter。`ceil(N/Br)` 是 query tile count，`ceil(N/Bc)` 是 key/value tile count；所有组合都整除，只为让 learner 先复核核心 ledger。

## 三阶段

1. **Score**：物化路径读取 Q/K 并写完整 `S=QK^T/sqrt(d)`；tiled 路径只形成 `Br×Bc` temporary scores。
2. **Normalize**：物化路径为 stable softmax 三次读取 S 并写 P；tiled 路径合并 online `(m,l)` state，S/P 不跨该 boundary。
3. **Value**：物化路径读取 P/V 并写 O；tiled 路径让 V 随 query tiles 重读，保留 accumulator `a`，最终写 `O=a/l`。

Exact tiled recurrence 实际交错 normalization 与 value aggregation。Stage selector 是概念分账，不声称三个独立 kernels 或某个 backend dispatch。Exact 表示实数算术下与 dense attention 等价，不表示 floating-point bitwise identity。

## IO 账本

对 self-attention `N,d` 与 `Tr=ceil(N/Br)`，完整 S/P 加 stable three-pass normalization 的元素数是 `4Nd + 6N^2`。Query-outer tiled schedule 的元素数是 `2Nd + 2TrNd`：Q/O 各跨 boundary 一次，K/V 各跨 boundary `Tr` 次，完整 S/P 从不物化。

默认 `N=8,d=4,Br=Bc=4` 得到物化路径 `512 elements = 2048 B`，tiled 路径 `192 elements = 768 B`，静态分析差值 `1280 B`。Normalize card 的 `0 B` 只表示没有该阶段的 slow-store transfer，不表示没有指数、max、sum 或 rescale 工作。

更大的 query tile 在这个简化 ledger 中减少 K/V replay，但模型没有 fast-store capacity、register pressure、occupancy、parallelism 或 spill，所以不能据此宣布 `8×8` 是更快或更好的 tile。
