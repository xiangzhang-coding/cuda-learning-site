## 学习目的

完成先修学习单元 **A05** 后，用 VIS11 把 tiled transpose 的数学映射与 shared-memory 物理布局拆开检查。相关 Runnable Example 是 **EX14**。这个 Visual Explainer 只处理一个 `4 × 4` 或 `8 × 8` 方形 tile；它让每个 input cell 的来源坐标、destination 坐标、row-major index 和 physical shared slot 都可直接核对。

## 控件

三个原生 select 分别选择 reviewed tile size `4` 或 `8`、logical layout `input-row-major` 或 `output-row-major`，以及每个 physical shared row 的 padding `0` 或 `1`。**重置**恢复 `4 / input-row-major / 0`，并把焦点返回 tile-size select。原生 select 与 button 自带键盘行为；状态区使用 polite live announcement。

控件和 live workbench 在 source HTML 中均带 `hidden`。Light-DOM custom element 只有在找到完整控件、状态区、input/output grid 与 physical-row 容器，并成功推导初始 model 后才显示它们。页面没有 autoplay、timer、randomness、browser storage、range input 或 persisted state。

## Transpose 映射

对 tile size `N`，input cell `(row, col)` 的 row-major index 是 `inputIndex = row × N + col`。Transpose 把它映射到 output `(col, row)`，所以 `outputIndex = col × N + row`。Input grid 始终按 `inputIndex` 递增，output grid 始终按 `outputIndex` 递增；两者显示的是同一组 `N²` 个逻辑值的 before/after 坐标，而不是两份数值计算。

例如 `N = 4` 时，input `(1, 2)` 的 `inputIndex` 是 `6`，映射到 output `(2, 1)`，`outputIndex` 是 `9`。模型对全部 logical cell 使用同一公式，不查询 device、warp、transaction 或 bank。

## Logical layout 与 physical padding

`input-row-major` 把 logical cell 放在 shared `(row, col)`；`output-row-major` 把同一 cell 放在 shared `(col, row)`。这两个选择改变 physical shared 中的数据槽排列，但都保留 `input(row, col) -> output(col, row)` 的逻辑映射。

Physical row stride 明确为 `tileSize + padding`，slot index 为 `sharedRow × stride + sharedCol`。Padding 为 `1` 时，每一行末尾增加一个明确写作“Padding 槽，无逻辑值”的 physical slot；它没有 input/output coordinate，不参与 transpose，也不改变 output index。Padding 为 `0` 时页面明确写出没有 padding slot。

这里的 layout 与 padding 只是地址算术。它们没有观察 shared-memory bank mapping、bank conflict、global-memory coalescing、同步、latency、bandwidth 或 speedup。任何真实 kernel 仍需独立证明 bounds、cooperative load、barrier participation、global access pattern 与 correctness。

## 静态回退

交互区之外永久 server-render 四种 tile-size/padding selection：`4/0`、`4/1`、`8/0` 与 `8/1`。每种 selection 都有 purpose-built input before grid、output after grid，以及 `input-row-major` 和 `output-row-major` 两套 physical rows；静态 markup 不是 hidden live DOM 的复制品。

四个 selection 共包含 160 个 input logical cell、160 个 output logical cell、48 条 physical row、344 个 physical slot，其中 24 个是带 slot index、row、column 与“无逻辑值”文字的 padding slot。禁用 JavaScript、390-pixel viewport、reduced motion、forced colors 与 print 时，静态内容仍保留。坐标、index、箭头、边框样式与文字共同承载含义，不只依赖颜色。

## 证据边界

VIS11 不编译或执行 CUDA、不加载 kernel、不查询 GPU、不读取 profiler，也不生成 measured timing、transaction、bank-conflict 或 performance observation。Browser model 的映射、stride 与 slot index 是 declared arithmetic，不是 CUDA execution、correctness 或 speed evidence。

因此 compilation、runtime、expected-observation 与 recorded-observation arrays 全部为空。页面不会授予 **Compile-Checked**、**Community-Observed** 或 **Runtime-Verified** Evidence Status。
