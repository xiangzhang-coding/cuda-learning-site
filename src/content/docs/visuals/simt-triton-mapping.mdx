## 用途

改变问题长度与逻辑块形状，再跟踪每个索引的归属。CUDA 对照固定采用每块 32 个线程；Triton 的块范围独立设置。这是原创的确定性可视化讲解（Visual Explainer），不是测得的 GPU 布局。

## 前置知识

精确前置为 **[T01]**：[程序实例与块值](/triton/programs-and-block-values/)。接着通过 [T02](/triton/masked-vector-addition/) 与 [EX23](/examples/triton-vector-add/) 学习带掩码内存操作。

## 解读结果

`N=37, B=16` 时，程序实例（program instance）2 负责逻辑索引 32–47，但只有 32–36 可以读取或写入。索引 36 映射到 CUDA 块 1、线程/通道（lane）4，以及 Triton 逻辑位置 4。Triton 位置标签不标识编译后的物理通道。设置 `N=1003, B=256` 可匹配 EX23 的逻辑形状；固定的每块 32 线程 CUDA 对照仍用于说明概念，不是 EX02 的精确启动配置。

键盘控制与即时更新不需要动画。禁用 JavaScript 或打印时，静态三实例表与初始表仍可使用；窄屏将静态卡片纵向排列，宽表可用键盘横向滚动。掩码有效性有文字标签，不依赖颜色。不持久保存设置，也不授予证据状态（Evidence Status）。
