## 证据边界

VIS01-VIS12、VIS14 与 VIS19-VIS22 都只在浏览器中运行确定性教学模型，保留静态或文字回退，并且不执行 CUDA。VIS14 的完整六叶决策树是永久静态回退；它不启动 `nsys` 或 `ncu`，不打开或解析 profiler report，不查询 GPU、CUPTI activity、metric 或 performance counter，而且 compilation、runtime、expected-observation 与 recorded-observation arrays 全为空。VIS12 的 matrix/tile/thread-block/warp/instruction panels 不是 emitted instruction、runtime、timing 或 performance observation。交互、静态回退与工具文档均保持 evidence-neutral；十七项讲解都没有 CUDA Evidence Status。复核日期：**2026-08-31**。
