## 顺序与直接查找

规划 ID 是稳定的讨论标签，不会生成或承诺固定 URL。卡片目的地可以是独立页面，也可以是学习单元内的明确锚点；你可以直接打开当前卡片，或先沿相关学习单元回到建立该概念的课程位置。

## 证据边界

VIS01、VIS02、VIS19、VIS20、VIS21 与 VIS22 都只在浏览器中运行确定性教学模型，不执行 CUDA。索引明确显示这一边界，且不会为这六项可视化讲解声明 Compile-Checked、Community-Observed 或 Runtime-Verified。
