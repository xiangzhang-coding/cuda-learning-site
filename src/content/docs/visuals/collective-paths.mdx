## 解释路径，不声称选中了算法

每个 rank r 贡献单元素向量 `[r+1]`。选择全归约（All-reduce）、rank 0 广播（Broadcast）或全收集（All-gather），选择 2、4、8 个 rank 及有向环或星形拓扑（Topology）。除广播外，模型先把贡献收集到 rank 0，在那里计算，再分发。All-gather 按 rank 拼接，all-reduce 求和。每一步沿一条允许边转发一份载荷。改变控件会返回第一跳，重置恢复四 rank 环形 all-reduce。

环形路径从源沿正向走到目标；星形经 rank 0 中转。两者都不是 NCCL 实现或实测拓扑。步数不代表延迟，载荷是合成值，不是 EX24 日志。表格标注的是**预期最终输出**，不是部分完成的设备状态。静态图与文字在禁用 JavaScript 及打印时仍可使用。这里有意不使用动画，也适用于减少动态效果模式。键盘控件与文字提供和大号路径显示相同的信息。
