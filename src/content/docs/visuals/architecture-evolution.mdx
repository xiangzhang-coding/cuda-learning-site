## 控件

选择**精确计算能力**与**所需功能**，取交集：8.9 加 TMA 或 12.1 加原生 FP64 Tensor Core 给出有解释的空结果，不改变 CC。重置恢复全部十二种状态，并聚焦 CC 选择框。使用原生键盘控件和礼貌播报。没有动画、自动播放、定时器、随机数、持久化或 GPU 查询。未知筛选值被拒绝并保留此前选择。

## 模型契约

固定顺序：7.5、8.0、8.6、8.7、8.9、9.0，随后 Blackwell 10.0、10.3、10.7、11.0、12.0、12.1。每个状态有目标、每块内存上限和十三项功能判断。FP64 指**原生 Tensor Core 输入**，不是普通 double 算术；8.0、9.0、10.0、10.7 合格。FP4 和家族目标筛选选择六个 Blackwell 状态。精度、API、形状／布局、参与及目标门槛仍适用；硬件可用不能证明所选指令。

每块上限为 64/163/99/163/99/227/227/227/327/227/99/99 KiB。超过 48 KiB 需动态分配和显式启用；10.7 超额配置需附加模式。这不是占用率或显存测量。本站基础范围仍是 CC 7.5+ 且问题适合 8 GB；现代单 GPU 能力层级（Modern Single-GPU Capability Tier）要求 CC 8.0+ 且至少 8 GB。表格行不选择运行平台。文档中的 10.7 不属于 EX25 固定的 13.3.1 构建配置。

L2 策略始于 8.0；查询实际容量和 MIG/MPS／窗口／预留区限制。集群／DSM／TMA 筛选选择 Hopper 和已核对 Blackwell 行。资源、生命周期、对齐、事务等待与代理可见性门槛仍适用。矩阵下方文字给出精确 `a`/`f` 范围，它们不授权全部 Blackwell 设备。H05/H06 定义编译器／设备准入及普通回退；EX25/LAB19/LAB20 提供可执行比较契约。
