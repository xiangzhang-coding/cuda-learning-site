## 学习目的

VIS03 是与 M06 相关的独立 Visual Explainer。它先用逐 lane 的谓词（predicate）解释线程束分支发散（warp divergence），再把控制流重汇合（reconvergence）与同步明确分开。

## Predicate mask

模型始终从包含 lane `0` 到 `31` 的参与掩码（participating mask）开始。所选 predicate 把这个集合分成真值掩码（true mask）与假值掩码（false mask）：

```text
trueMask  = { lane in participatingMask | predicate(lane) is true }
falseMask = { lane in participatingMask | predicate(lane) is false }

trueMask intersection falseMask = empty
trueMask union falseMask = participatingMask
```

五种经过复核的 preset 固定了 partition：uniform true、uniform false、lower half（`0` 到 `15`）、偶数 lane alternating，以及一组固定的 non-contiguous lane。Uniform preset 必有一条空路径。空路径会明确显示为**跳过（skipped）**，而不是消失或被当作失败阶段。

## 路径跟踪

五个教学阶段依次是 `before-branch`、`predicate-evaluated`、`true-path`、`false-path` 与逻辑汇合（logical join）。VIS03 固定先显示 true path，再显示 false path，让 Step 的结果可重复。这个顺序**不是硬件调度顺序**，不能用于预测 warp scheduler 先 issue 哪条 path。

到达 logical join 时，32 个 lane 构成拥有共同 control-flow successor 的**源代码级参与集合（source-level participating set）**。这不表示它们共享同一条当前指令或同一个当前 active mask；Independent Thread Scheduling 可能在执行过程中重新组合 sub-warp。Logical join **不是内存同步**：它不是 `__syncwarp()`、block barrier、memory fence，也不证明 memory communication 安全。

## Independent Thread Scheduling 边界

在 compute capability 低于 7.0 的设备上，一个 warp 使用共享 program counter 和活动掩码（active mask）。在 **CC 7.0+** 上，独立线程调度（Independent Thread Scheduling）保存 per-thread execution state，并允许 sub-warp divergence 与 reconvergence。因此，依赖隐式锁步（implicit lockstep）、把 lane 假定为在每条指令上永久同步执行，可能导致错误。需要 coordination 时，必须选择符合 communication contract 的显式 primitive；例如在适用时用带正确 participating mask 的 `__syncwarp()`。

Lane table 只是 predicate 与 control-flow model。Logical-join column 表示 source-level participating set，不表示当前 instruction 或 active mask；它不暴露 instruction trace、scheduler trace、latency，也不声明硬件实际选择的 sub-warp grouping。

## 静态回退

永久 fallback 含两张完整的 32-row table。Lower-half table 展示两条非空 path；uniform-true table 把 false path 标为 skipped。`ACTIVE`、`INACTIVE` 与“跳过”等文字承担语义，所以颜色绝不是唯一差异。禁用 JavaScript 和打印时，这些 table 仍然可用。

## 证据边界

VIS03 不编译或运行 CUDA、不读取 GPU，也不记录 timing。确定性 mask 不会授予 **Compile-Checked**、**Community-Observed** 或 **Runtime-Verified**。Compilation、runtime、expected-observation 与 recorded-observation metadata 均为空。
