## 顺序与直接查找

规划 ID 是跨课程讨论和维护时使用的稳定标签，不是 URL 稳定性承诺。请使用卡片中的当前链接；进入实验前仍需沿卡片列出的先修学习单元（Learning Unit）完成顺序学习。

## 证据边界

卡片中的编译和运行状态直接复制自链接实验的受控证据字段，不会把网站构建、筛选或浏览器测试升级为 CUDA 证据。当前 LAB02 的运行轴仍为 Pending Hardware Verification。
