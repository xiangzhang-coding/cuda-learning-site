## 证据边界

卡片中的编译和运行状态直接复制自链接实验的受控证据字段，不会把网站构建、筛选或浏览器测试升级为 CUDA 证据。既有 LAB01-LAB10 状态不变。LAB11 的 compilation evidence 与 recorded observations 为空、没有 observed runtime evidence，runtime 为待硬件验证（Pending Hardware Verification），只发布 expected observations；没有 Reference Environment 或 `performanceObservations`。其 expected-only fixture 不是采集所得 `.ncu-rep`，也没有 CUB output、temporary-storage value、kernel mapping、timing、metric、traffic、speedup、maintenance score 或 winner。EX17 的 compilation evidence 同样为空且 runtime 待硬件验证；声明的 component matrix 是 non-evidentiary build gate，并不表示 CI 已运行。

新增 LAB12 与 EX18 的编译证据和实际观察记录也为空，运行状态均为待硬件验证（Pending Hardware Verification）。LAB12 提供匹配输入、逐次正确性检查和原始计时样本的采集步骤，不发布已测得的输出、耗时、加速比或赢家。预期观察不是实际观察；发布页面、主机检查和浏览器测试不会升级其证据状态。L06/L07 的四个证据数组保持为空。
