## 当前发布路线

稳定课程（Stable Curriculum）的 O01-O08 导学部分已经完整发布。严格先修图从首页进入 O01：O02、O03、O04、O05 和 O06 都直接依赖 O01；O07 依赖 O06；O08 同时依赖 O02、O03 和 O05。LAB01 同时依赖 O03 和 O08，并使用 EX01 环境报告可运行示例（Runnable Example）。EX01 没有编译已检查（Compile-Checked）声明，EX01 和 LAB01 的运行轴均为待硬件验证（Pending Hardware Verification）。原有 kernel 路线仍由 O03 进入 F01，再到 LAB02；EX02 仍是 F01/LAB02 共享的 canonical source。

O04-O08 都提供完整练习（Exercise）和独立参考解答：[O04 练习](/start/cpp17-for-cuda/exercises/)与[解答](/start/cpp17-for-cuda/solutions/)、[O05 练习](/start/linux-command-line/exercises/)与[解答](/start/linux-command-line/solutions/)、[O06 练习](/start/architecture-refresher/exercises/)与[解答](/start/architecture-refresher/solutions/)、[O07 练习](/start/programmable-gpus/exercises/)与[解答](/start/programmable-gpus/solutions/)、[O08 练习](/start/reference-environment-candidate/exercises/)与[解答](/start/reference-environment-candidate/solutions/)。实验（Lab）、练习题库（Practice Bank）、可视化讲解（Visual Explainer）、术语和来源也提供直接索引。路线不会用空页面代替尚未完成的材料。

## 边界先说清

这里维护一套按先修关系组织的稳定课程（Stable Curriculum），但网站本身保持静态：没有账号、学习进度、测验分数、服务端渲染或应用 API，也不会在浏览器里编译或执行 CUDA。需要动手的活动会说明如何在站外环境中完成。
