## 当前发布路线

稳定课程（Stable Curriculum）现已完整发布 O01-O08 导学与 F01-F04 基础学习单元。严格先修图从首页进入 O01：O02、O03、O04、O05 和 O06 都直接依赖 O01；O07 依赖 O06；O08 同时依赖 O02、O03 和 O05。LAB01 同时依赖 O03 和 O08，并使用 EX01 环境报告可运行示例（Runnable Example）。Kernel 路线由 O03 进入 [F01](/foundations/first-cuda-kernel/)；[F02 执行层次](/foundations/execution-hierarchy/)依赖 F01，[F03 多维索引](/foundations/multidimensional-indexing/)依赖 F02，[F04 host-device 生命周期](/foundations/host-device-lifecycle/)也依赖 F01。[EX03 多维索引](/examples/multidimensional-indexing/)依赖 F03，并为 F03/F04 提供 canonical source；LAB02 仍依赖 O03 和 F01，并使用 EX02。

F01-F04 都提供完整练习（Exercise）和独立参考解答：[F01 练习](/foundations/first-cuda-kernel/exercises/)与[解答](/foundations/first-cuda-kernel/solutions/)、[F02 练习](/foundations/execution-hierarchy/exercises/)与[解答](/foundations/execution-hierarchy/solutions/)、[F03 练习](/foundations/multidimensional-indexing/exercises/)与[解答](/foundations/multidimensional-indexing/solutions/)、[F04 练习](/foundations/host-device-lifecycle/exercises/)与[解答](/foundations/host-device-lifecycle/solutions/)；O02-O08 也保留各自的练习与独立解答。EX03 在 11.8.0、12.9.2 和 13.3.1 三条工具包通道（Toolkit Lane）共用一份原创 C++17 source，并提供 host-only checks，但 compilation evidence 为空，因此不是 Compile-Checked；运行状态为 Pending Hardware Verification。本站没有运行 EX03 CUDA binary，也不发布 EX03 性能数字。本轮扩展复用 VIS01/VIS02；F04 的原创静态生命周期表不是新的 Visual Explainer，也不是证据来源。导航仍只公开 LAB01/LAB02，不显示 LAB03 或未完成学习单元；练习题库现有十三道完整条目，术语表和来源记录也已扩展。

## 边界先说清

这里维护一套按先修关系组织的稳定课程（Stable Curriculum），但网站本身保持静态：没有账号、学习进度、测验分数、服务端渲染或应用 API，也不会在浏览器里编译或执行 CUDA。需要动手的活动会说明如何在站外环境中完成。
