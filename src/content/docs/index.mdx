## 当前发布路线

稳定课程（Stable Curriculum）现已完整发布 O01-O08 导学与 F01-F08 基础学习单元。严格先修图从首页进入 O01：O02、O03、O04、O05 和 O06 都直接依赖 O01；O07 依赖 O06；O08 同时依赖 O02、O03 和 O05。LAB01 同时依赖 O03 和 O08，并使用 EX01 环境报告可运行示例（Runnable Example）。Kernel 路线由 O03 进入 [F01](/foundations/first-cuda-kernel/)；[F02 执行层次](/foundations/execution-hierarchy/)依赖 F01，[F03 多维索引](/foundations/multidimensional-indexing/)依赖 F02，[F04 host-device 生命周期](/foundations/host-device-lifecycle/)也依赖 F01。[F05 异步错误](/foundations/asynchronous-errors/)仅依赖 F04；[F06 compute capability](/foundations/compute-capability/)同时依赖 F02 和 O03；[F07 Runtime/Driver API 边界](/foundations/runtime-driver-api/)同时依赖 F04 和 F05；[F08 launch geometry](/foundations/launch-geometry/)同时依赖 F02、F03 和 F06。[EX03 多维索引](/examples/multidimensional-indexing/)依赖 F03，并为 F03/F04 提供 canonical source；[EX04 错误处理生命周期](/examples/error-handling-lifecycle/)仅依赖 F05。LAB02 依赖 O03 和 F01，并使用 EX02；[LAB03 破坏并修复索引](/labs/break-and-repair-indexing/)同时依赖 F03 和 F05，并使用 EX04。F08 与 LAB03 相关，但不是 LAB03 的先修条件。

F01-F08 都提供完整练习（Exercise）和独立参考解答：[F01 练习](/foundations/first-cuda-kernel/exercises/)与[解答](/foundations/first-cuda-kernel/solutions/)、[F02 练习](/foundations/execution-hierarchy/exercises/)与[解答](/foundations/execution-hierarchy/solutions/)、[F03 练习](/foundations/multidimensional-indexing/exercises/)与[解答](/foundations/multidimensional-indexing/solutions/)、[F04 练习](/foundations/host-device-lifecycle/exercises/)与[解答](/foundations/host-device-lifecycle/solutions/)、[F05 练习](/foundations/asynchronous-errors/exercises/)与[解答](/foundations/asynchronous-errors/solutions/)、[F06 练习](/foundations/compute-capability/exercises/)与[解答](/foundations/compute-capability/solutions/)、[F07 练习](/foundations/runtime-driver-api/exercises/)与[解答](/foundations/runtime-driver-api/solutions/)、[F08 练习](/foundations/launch-geometry/exercises/)与[解答](/foundations/launch-geometry/solutions/)；O02-O08 也保留各自的练习与独立解答。

EX03 保留现有状态：三条工具包通道（Toolkit Lane）共用一份原创 C++17 source，host-only checks 不编译或运行 CUDA，compilation evidence 为空，runtime 为 Pending Hardware Verification。EX04 与 LAB03 的 compilation evidence 也都为空，runtime 都是 Pending Hardware Verification。本站没有运行 EX03 或 EX04 CUDA binary，也不发布它们的实际输出、错误码、计时或性能数字。

正式的可视化讲解（Visual Explainer）路线仍只有 VIS01/VIS02。F05 的错误时间线、F06 的 capability filter、F07 的 API boundary 和 F08 的 block-shape explorer 是四个原创内嵌教学界面，不是独立 Visual Explainer，也没有新的 VIS 路由；它们都有静态或文字回退，不执行 CUDA，不产生 Evidence Status。F04 的原创静态生命周期表同样不是 Visual Explainer 或证据来源。导航现已公开 LAB01-LAB03；练习题库现有十七道完整条目，术语表和来源记录也已扩展。

## 边界先说清

这里维护一套按先修关系组织的稳定课程（Stable Curriculum），但网站本身保持静态：没有账号、学习进度、测验分数、服务端渲染或应用 API，也不会在浏览器里编译或执行 CUDA。需要动手的活动会说明如何在站外环境中完成。
