## 当前发布路线

当前稳定入口是 **首页 → O01 → O03 → F01：从预测到第一个 CUDA kernel → LAB02：运行并验证向量加法**。O02 提供贯穿路线的证据状态（Evidence Status）合同，EX02 是 F01/LAB02 共享的 canonical 可运行示例（Runnable Example），VIS01/VIS02 提供 kernel 路径与索引可视化讲解（Visual Explainer）。学习单元（Learning Unit）配有练习（Exercise）和独立解答；实验、练习题库（Practice Bank）、可视化讲解、术语和来源都提供直接索引。路线不会用空页面代替尚未完成的材料。

## 边界先说清

这里维护一套按先修关系组织的稳定课程（Stable Curriculum），但网站本身保持静态：没有账号、学习进度、测验分数、服务端渲染或应用 API，也不会在浏览器里编译或执行 CUDA。需要动手的活动会说明如何在站外环境中完成。
