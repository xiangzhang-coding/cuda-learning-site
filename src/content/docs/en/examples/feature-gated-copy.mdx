## Purpose and prerequisite

Exact prerequisite: [H06](/en/architecture/portable-specialization/). Copy 256/4096/65536 int32 values through shared tiles with 128 threads/block and 256 values/tile. Compare the explicit ordinary baseline with a target-admitted bulk-copy load/consume pipeline. This is one stage, with no overlap claim or precision change.

## Explicit dispatch

<CanonicalCode exampleId="EX25" range="dispatch" />

`portable` forces the baseline; `auto` selects specialization only when admitted; `specialized` rejects unsupported devices before launch. An admitted specialized run always checks the portable path first. Invalid modes fail. CC 10.7 is documented but outside this build profile. Runtime device 0, driver/runtime versions and memory are queried; at least 8 GB total and 512 MiB free are required. CUDA errors terminate instead of silently changing path.

## Independent integer oracle

<CanonicalCode exampleId="EX25" range="oracle" />

Three patterns exercise signed index-varying values, zero and alternating ±100000. Output guards use a value outside all patterns. Check every result and all eight guards after stream completion and again after timing. Host mutation tests verify rejection at every position; they never execute CUDA. Two guarded arrays use at most **524352 B**; each payload starts at a 16 B offset from its aligned allocation.

## Portable shared-memory baseline

<CanonicalCode exampleId="EX25" range="portable" />

One 1024 B tile, ordinary loads, a block barrier and ordinary stores. Neighbor-permuted ownership makes each thread consume another thread's shared element. All counts are whole tiles; no unchecked tail is allowed. The baseline is compiled separately for ordinary 75 PTX/cubin and, in specialized builds, a matching numeric target cubin.

## Feature-gated bulk-copy path

<CanonicalCode exampleId="EX25" range="specialized" />

Only thread 0 initializes and arrives on the 8 B barrier. It registers exactly 1024 expected bytes, issues the aligned copy and waits phase zero. A block barrier publishes completion; a final barrier protects lifetime before invalidation. No cluster, tensor map, multicast, TMA store or family-exclusive instruction is used. The same protocol is built under different exact target scopes; suffix choice does not prove performance.

The project manifest pins container digests. From the standalone directory:

```sh
make host-test
bash scripts/compile-check.sh 90
timeout 120s ./build/90/ex25-copy portable
timeout 120s ./build/90/ex25-copy specialized
```

Use the selected Blackwell target instead of 90 for [LAB20](/en/labs/blackwell-portable-comparison/); [LAB19](/en/labs/hopper-portable-comparison/) requires CC 9.0. Compile checks preprocess, compile, link and inspect without running the device executable. `cuobjdump` PTX output should retain the suffixed target and bulk-copy instruction; ELF filenames alone may omit the suffix. Preserve actual output, not just a command exit status.

The executable emits path/count/pattern correctness fields and ten raw 100-launch batch timings after five warmups. Event intervals exclude transfers and initialization. Capture exit status, use a separate authorized profiler pass and follow the Labs' Environment Manifest/record protocol. Expected field names are not recorded GPU output.
