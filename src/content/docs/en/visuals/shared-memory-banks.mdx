## Learning purpose

VIS05 is the deterministic address-to-bank mapper related to [M04](/en/memory/bank-conflicts-layouts/) and [EX06](/en/examples/shared-memory-tile-bank-padding/). It makes each lane’s selected 4-byte word, byte address, and bank visible before any optimization claim is considered.

## Mapping model

The default source-backed fixture is inside this site’s CC 7.5+ Baseline GPU Capability Tier and contains `32` lanes, `32` banks, and 4-byte words. For lane `L`, stride `S`, padding `P`, and bank count `B`, the abstract layout is:

```text
laneStep  = S + P
wordIndex = L * laneStep
byte      = wordIndex * 4
bank      = wordIndex mod B
```

Bank count is controllable so the arithmetic can be inspected directly. Only the default `32`-bank, successive-4-byte-word fixture is presented as the reviewed CUDA rule; other bounded bank counts are abstract comparisons and do not claim a supported architecture.

## Classification

The mapper groups lanes by bank, then counts **distinct word addresses** in each bank. Conflict degree is the largest such count. A degree of one is conflict-free when lanes address different banks or when each addressed bank contains only one distinct word.

This fixture models one shared-memory **read**. If all lanes request the same word, the result is classified separately as **same-address broadcast**, with one distinct address rather than a 32-way conflict. Same-address writes are intentionally outside VIS05 because their semantics are not the read-broadcast case.

Conflict degree is a structural property of this selected address list. It is not elapsed time, serialization duration, bandwidth, or speedup, and the browser cannot decide how a complete kernel will perform.

## Stride and padding cases

With `32` banks and padding `0`, stride `1` visits every bank once and is conflict-free. Stride `2` reaches 16 banks with two distinct addresses per bank, so it is two-way. Stride `32` sends 32 distinct addresses to bank zero, so it is 32-way.

Changing stride `32`, padding `0` to stride `32`, padding `1` changes the lane step from `32` to `33`. Since `33 mod 32 = 1`, consecutive lanes rotate across all 32 banks and the mapped read becomes conflict-free. This is address arithmetic, not a promise that padding improves every kernel.

## Static fallback

Five cards preserve stride `1`, stride `2`, stride `32`, padded stride `33`, and same-address broadcast. They are produced by the same pure model as the interactive table and remain complete with JavaScript disabled and in print.

## Evidence boundary

VIS05 compiles and executes no CUDA, reads no GPU, and measures no latency. Its mapping and conflict labels grant no **Compile-Checked**, **Community-Observed**, or **Runtime-Verified** status. Compilation, runtime, expected-observation, and recorded-observation metadata are all empty.
