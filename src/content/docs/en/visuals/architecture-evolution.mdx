## Model contract

Fixed order: 7.5, 8.0, 8.6, 8.7, 8.9, 9.0, then Blackwell 10.0, 10.3, 10.7, 11.0, 12.0, 12.1. Each state has targets, a per-block memory ceiling and thirteen feature decisions. FP64 means **native Tensor Core inputs**, not ordinary double arithmetic: 8.0, 9.0, 10.0 and 10.7 qualify. FP4 and family-target filters select the six Blackwell states. Precision, API, shape/layout, participation and target gates still apply; hardware availability does not prove selected instructions.

Per-block ceilings are 64/163/99/163/99/227/227/227/327/227/99/99 KiB. Above 48 KiB requires dynamic allocation and opt-in; 10.7's oversized configuration requires its additional mode. These are not occupancy or VRAM measurements. Site baseline remains CC 7.5+ and problems fitting within 8 GB; Modern Single-GPU requires CC 8.0+ and at least 8 GB. A row selects no runtime platform. Documented 10.7 is outside EX25's fixed 13.3.1 build profile.

L2 policy starts at 8.0; query actual capacity and MIG/MPS/window/set-aside limits. Cluster/DSM/TMA select Hopper and the reviewed Blackwell rows. Resource, lifetime, alignment, transaction wait and proxy-visibility gates still apply. The text beneath the matrix gives exact `a`/`f` scopes; they do not authorize every Blackwell device. H05/H06 define compiler/device admission and ordinary fallback; EX25/LAB19/LAB20 supply the executable comparison contract.
