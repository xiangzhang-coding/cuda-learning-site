## Purpose

Change problem length and logical block shape, then trace the owner of each index. CUDA uses a fixed 32-thread comparison block; Triton's block extent is independent. This is an original deterministic Visual Explainer, not a measured GPU layout.

## Prerequisites

Exact prerequisite **[T01]**: [programs and block values](/en/triton/programs-and-block-values/). Continue with [T02](/en/triton/masked-vector-addition/) and [EX23](/en/examples/triton-vector-add/) for masked memory operations.

## Interpret the result

For `N=37, B=16`, program 2 owns logical indices 32–47, but only 32–36 may load/store. Index 36 maps to CUDA block 1, thread/lane 4 and Triton logical position 4. The Triton position label does not identify its compiled physical lane. Set `N=1003, B=256` to match EX23's logical shape; the fixed 32-thread CUDA comparison remains illustrative rather than EX02's exact launch configuration.

Keyboard controls and immediate updates require no animation. The static three-program ledger and initial table survive disabled JavaScript and print; narrow screens stack the static cards and keep wide tables keyboard-scrollable. Mask validity has text labels and does not depend on color. No settings persist, and no Evidence Status is awarded.
