## Interpret the path without claiming an algorithm

Each rank r contributes the one-element vector `[r+1]`. Choose all-reduce, rank-zero broadcast or all-gather; choose 2, 4 or 8 ranks and directed ring or star topology. Except broadcast, the model gathers contributions at rank 0, computes the result there, then distributes it. All-gather concatenates in rank order; all-reduce sums. Every step forwards one payload over one allowed edge. Changing controls resets the hop to the first step; reset restores four-rank ring all-reduce.

The ring routes from each source forward until the destination; the star goes through rank 0. Neither is an NCCL implementation or a measured topology. Step count is not latency, and payload values are synthetic, not EX24 logs. The table labels **expected final output**, not partially completed device state. The static diagrams and text remain available without JavaScript and in print. Motion is deliberately absent, including reduced-motion mode. Keyboard controls and text give the same information as the large path display.
