## Sequence and direct lookup

The current sequence lists [LAB01: Record and Interpret a CUDA Environment](/en/labs/record-cuda-environment/), [LAB02: Run and Verify Vector Addition](/en/labs/vector-addition/), and [LAB03: Break and Repair Indexing](/en/labs/break-and-repair-indexing/). A host-only test, learner-local build, or expected observation changes none of these statuses.
