## Lab contract

Build one original adjacent-energy operator, register and differentiate it, test both native paths and install the same ahead-of-time wheel into a clean matching environment. Allow about 120 minutes plus environment provisioning. The website runs no CUDA. A GPU-free build/CPU check is useful progress, but completing this Lab requires the CUDA checks and complete records below. Current status is **Pending Hardware Verification**, not a prefilled success report.

## Prepare and predict

Provision the declared Python, GCC and Toolkit. Create and activate a fresh virtual environment with that interpreter. From the downloaded repository root run:

```sh
python -I scripts/pytorch-environment/check.py --install
```

This installs and checks the existing exact application closure before EX22 adds its own distribution. Preserve that phase's exit code. Make a learner-owned external copy of EX22's blank `environment-manifest.json`; target requirements must not fill observation fields.

Predict the literal input [1,-2,2,2.5], the weighted gradient for g=[1,2,3], the singleton output/gradient and n=258 launch shape. Answers should be [9,16,0.25], [6,-22,13,3], empty/one zero, and 257 outputs in two 256-thread blocks. These are algebraic predictions, not run output. Explain them before executing.

## Build and install the canonical wheel

bash scripts/check-wheel.sh

## Validate values, metadata and gradients

<CanonicalCode exampleId="EX22" range="checks" />

After the host gate succeeds, select one suitable visible GPU and run:

```sh
python -I verify.py --device cuda
```

The verifier rejects unavailable/insufficient hardware, exercises the non-default current stream and joins completion. It checks all forward outputs and preserved inputs, nonuniform upstream gradients, float64 gradcheck and gradgradcheck, opcheck, explicit meta calls, and fullgraph dynamic forward/backward. Sizes 1, 2, 256, 257, 258 and 1003 cover empty output and block boundaries. Offset-contiguous inputs are accepted; empty, over-budget, strided, rank-two, integer and half inputs are rejected. Binary fractions justify exact forward tolerance; numerical derivative tolerances are eps=1e-6, atol=1e-5, rtol=1e-3. A mismatch, nonfinite result, launch or completion error fails the phase; preserve its first diagnostic.

## Prove packaging and import behavior

Hash the built wheel and installed extension with SHA-256. Create a **second** matching CPython venv, install the same application's hash-locked requirements from the repository root, and install that exact wheel with `python -m pip install --no-deps /absolute/path/to/wheel.whl`. Use your real wheel path; it is not an executable placeholder to paste unchanged. Run `python -m pip check`, then the same verification script through the second interpreter with `-I --device cpu`. The script's own path does not become a package import path in isolated mode.

Record the resolved `cuda_learning_ops` and `_C` paths; they must belong to the second environment's site-packages. Start a new process for each test. In that disposable environment, temporarily remove only the installed `_C` file and require a fresh isolated public import to fail even with the source checkout still present. Restore by reinstalling the original wheel, then require import to succeed. There must be no editable install, source fallback or import-time compilation. This negative test distinguishes artifact completeness from a cached/native module already loaded in one process.

## Expected observations and evidence boundary

Both native paths **should** build into one importable wheel. CPU and CUDA **should** satisfy the value, derivative, metadata and compiled-execution contracts. Removing the installed extension **should** fail import. These expectations are not observations. Compilation evidence is empty; runtime is **Pending Hardware Verification**; recorded observations are empty. A CI build does not automatically become Compile-Checked, and an arbitrary successful GPU run does not automatically become Runtime-Verified without Reference Environment review.
