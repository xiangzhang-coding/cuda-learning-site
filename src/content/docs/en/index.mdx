## The route published today

The stable entry runs from **Home to O01: Using the Learning Site**. After O01, learners can enter **O02: Recording Evidence Honestly** and **O03: Reading an Environment Manifest** as separate branches. Each branch has Exercises and separate solutions, while the Practice Bank links transfer problems back to their prerequisites. The route never substitutes empty pages for unfinished material.

## Boundaries first

The project maintains a prerequisite-bearing Stable Curriculum, while the website stays static. It has no account, progress profile, quiz score, server rendering, or application API, and it never compiles or executes CUDA in the browser. Hands-on activities give directions for work in an external environment.
