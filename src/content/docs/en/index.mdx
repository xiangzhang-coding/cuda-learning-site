## The route published today

The Stable Curriculum now completely publishes the O01-O08 orientation and foundational Learning Units F01-F04. The strict prerequisite graph enters O01 from Home. O02, O03, O04, O05, and O06 all depend directly on O01; O07 depends on O06; and O08 requires O02, O03, and O05. LAB01 requires both O03 and O08 and uses the EX01 environment-report Runnable Example. The kernel route enters [F01](/en/foundations/first-cuda-kernel/) from O03. [F02 Execution Hierarchy](/en/foundations/execution-hierarchy/) depends on F01, [F03 Multidimensional Indexing](/en/foundations/multidimensional-indexing/) depends on F02, and [F04 Host-Device Lifecycle](/en/foundations/host-device-lifecycle/) also depends on F01. [EX03 Multidimensional Indexing](/en/examples/multidimensional-indexing/) depends on F03 and supplies canonical source to F03/F04. LAB02 still requires O03 and F01 and uses EX02.

F01-F04 each publish complete Exercises and separate reviewed solutions: [F01 Exercises](/en/foundations/first-cuda-kernel/exercises/) and [solutions](/en/foundations/first-cuda-kernel/solutions/), [F02 Exercises](/en/foundations/execution-hierarchy/exercises/) and [solutions](/en/foundations/execution-hierarchy/solutions/), [F03 Exercises](/en/foundations/multidimensional-indexing/exercises/) and [solutions](/en/foundations/multidimensional-indexing/solutions/), and [F04 Exercises](/en/foundations/host-device-lifecycle/exercises/) and [solutions](/en/foundations/host-device-lifecycle/solutions/). O02-O08 retain their own Exercises and separate solutions. EX03 shares one original C++17 source across Toolkit Lanes 11.8.0, 12.9.2, and 13.3.1 and provides host-only checks, but its compilation evidence is empty, so it is not Compile-Checked; runtime is Pending Hardware Verification. The site ran no EX03 CUDA binary and publishes no EX03 performance number. This expansion reuses VIS01/VIS02. F04's original static lifecycle table is neither a new Visual Explainer nor an evidence source. Navigation still publishes only LAB01/LAB02, with no LAB03 or unfinished Learning Unit; the Practice Bank now contains thirteen complete entries, and the Glossary and source records are expanded.

## Boundaries first

The project maintains a prerequisite-bearing Stable Curriculum, while the website stays static. It has no account, progress profile, quiz score, server rendering, or application API, and it never compiles or executes CUDA in the browser. Hands-on activities give directions for work in an external environment.
