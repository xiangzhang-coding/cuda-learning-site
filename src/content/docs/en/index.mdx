## The route published today

The O01-O08 orientation of the Stable Curriculum is completely published. The strict prerequisite graph enters O01 from Home. O02, O03, O04, O05, and O06 all depend directly on O01; O07 depends on O06; and O08 requires O02, O03, and O05. LAB01 requires both O03 and O08 and uses the EX01 environment-report Runnable Example. EX01 has no Compile-Checked claim, and the runtime axes for EX01 and LAB01 are both Pending Hardware Verification. The existing kernel route still runs from O03 to F01 and then LAB02, with EX02 remaining the canonical source shared by F01/LAB02.

O04-O08 each publish complete Exercises and separate reviewed solutions: [O04 Exercises](/en/start/cpp17-for-cuda/exercises/) and [solutions](/en/start/cpp17-for-cuda/solutions/), [O05 Exercises](/en/start/linux-command-line/exercises/) and [solutions](/en/start/linux-command-line/solutions/), [O06 Exercises](/en/start/architecture-refresher/exercises/) and [solutions](/en/start/architecture-refresher/solutions/), [O07 Exercises](/en/start/programmable-gpus/exercises/) and [solutions](/en/start/programmable-gpus/solutions/), and [O08 Exercises](/en/start/reference-environment-candidate/exercises/) and [solutions](/en/start/reference-environment-candidate/solutions/). Labs, Practice Bank entries, Visual Explainers, terms, and source records also have direct indexes. The route never substitutes empty pages for unfinished material.

## Boundaries first

The project maintains a prerequisite-bearing Stable Curriculum, while the website stays static. It has no account, progress profile, quiz score, server rendering, or application API, and it never compiles or executes CUDA in the browser. Hands-on activities give directions for work in an external environment.
