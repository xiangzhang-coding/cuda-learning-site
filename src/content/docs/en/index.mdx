## The route published today

The stable route is **Home → O01 → O03 → F01: From Prediction to a First CUDA Kernel → LAB02: Run and Verify Vector Addition**. O02 supplies the Evidence Status contract across that route, EX02 is the canonical Runnable Example shared by F01/LAB02, and VIS01/VIS02 explain the kernel journey and indexing. Learning Units have Exercises and separate solutions. Labs, Practice Bank entries, Visual Explainers, terms, and source records also have direct indexes. The route never substitutes empty pages for unfinished material.

## Boundaries first

The project maintains a prerequisite-bearing Stable Curriculum, while the website stays static. It has no account, progress profile, quiz score, server rendering, or application API, and it never compiles or executes CUDA in the browser. Hands-on activities give directions for work in an external environment.
